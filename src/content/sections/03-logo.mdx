## Logotype

### Primary logo

</Fragment>

<Fragment slot="note">

The primary logo is a logotype: the brand name set in the brand face, spaced and drawn as
a single piece of artwork. It is the default in every context where there is room for it.

Always place the supplied file. Never re-set the name in the typeface — the logotype
carries custom spacing that live text will not reproduce.

</Fragment>

## Logotype

### On black

</Fragment>

<Fragment slot="note">

On dark surfaces the logotype reverses to white. There is no third version — the artwork
is identical, only the colour changes.

## Brandmark

### Monogram

</Fragment>

<Fragment slot="note">

A monogram of the initials, unified into one shape. It stands in for the logotype where
space is tight or the brand is already established in context: avatars, favicons, app
icons, stamped and embroidered applications.

## Logotype

### Scaling

</Fragment>

## Logo

### Misusage

</Fragment>

<Fragment slot="note">

Six ways to break the logo. Each one is a real mistake we have had to correct.

<Callout tone="dont" title="Also never">

Add a drop shadow, outline, gradient or bevel. Place the logo on a busy photograph without
a solid field behind it. Redraw or trace any part of the artwork.

</Callout>

</Fragment>
