<Callout type="note" title="Source paths and public URLs differ">

A config path beginning with `/` identifies a file under the consumer's `public/`
folder. A path beginning with `./` identifies a project-relative source file.
The [Brand assets guide](/brand-assets) explains every supported path form and
which pipelines can read filesystem sources.

</Callout>
