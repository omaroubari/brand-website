## Usage

Pass the current brand and interface strings to display the logotype’s clearspace.
Configure the artwork and `logo.clearspace` in [Logos](/logos).

```mdx
<LogoClearspace brand={props.brand} ui={props.ui} />
```

## Examples

### Show the logotype

The opening preview uses the brandmark. Omit `mark` to show the wider logotype
with the same configured clearspace rule.

<ComponentPreview path="logo-clearspace-logotype" code={variantCode} />

## Clearspace behavior

The diagram uses `brand.logo.clearspace.ratio` for its padding and
`brand.logo.clearspace.unit` in the localized caption. There is no per-instance
spacing override. Measurement ticks are hidden at viewport widths up to `34rem`;
the protected zone and caption remain visible.
