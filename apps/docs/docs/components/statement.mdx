## Usage

Write one or more Markdown paragraphs in the default slot. Paragraph breaks add
a full line of space between thoughts.

```mdx
<Statement>

We help people recognize what matters.

Every touchpoint should make that promise clear.

</Statement>
```

## Typography behavior

`Statement` inherits typography from its surrounding context; it currently does
not apply an oversized font treatment. It renders a `div` so Markdown-generated
paragraphs remain valid HTML. Supply the prose as children; there is no `text`
prop.
