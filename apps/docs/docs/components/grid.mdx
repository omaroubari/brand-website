## Usage

Wrap prose or other components in `Grid`. The grid itself needs no brand or
interface props; forward those to children that require them.

```mdx
<Grid cols={2}>
  <Figure ui={props.ui} caption="Front" />
  <Figure ui={props.ui} caption="Back" />
</Grid>
```

These figures render draft placeholders until you provide `src`. For image
imports and captions, see [Figure](/components/figure). The preview’s Code tab
includes an image import relative to a content-root page; use your own asset and
adjust the path for nested or localized content.

## Responsive behavior

Below `48rem`, the grid uses `colsSm`; at `48rem` and above, it uses `cols`.
The breakpoint follows the available width of the browser viewport, including
inside an embedded preview. Resize the page to compare the layouts.

Children render in document order. Use positive whole numbers for column counts
and spacing tokens such as `var(--space-l)` for gaps.
