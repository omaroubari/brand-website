`Grid` is available by name in Brandtree content MDX; no import is needed. Pass any required `brand`, `ui`, or `dir` props explicitly from `props.brand`, `props.ui`, and `props.dir`; the generated route supplies these values to the document. The optional `class` prop adds a class to the outer element; other HTML attributes are not forwarded automatically.

## Preview

The preview uses the sample brand. Copy the MDX from the Code tab into your own
page to render the same example with your configured brand. See [Usage](#usage)
for more options.

The media imports assume a page at the content root. Use your own assets and
adjust import paths for nested or localized pages.

Arrange children in a responsive grid. Optional props: `cols` (number, default `3`, medium screens upward), `colsSm` (number, default `1`), `gap` (CSS length; omitted uses `var(--space-m)`), `class`.

## Usage

```mdx
<Grid cols={2} colsSm={1} gap="var(--space-l)">
  <Figure ui={props.ui} caption="Front" />
  <Figure ui={props.ui} caption="Back" />
</Grid>
```
