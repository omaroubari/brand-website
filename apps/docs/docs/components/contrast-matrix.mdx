`ContrastMatrix` is available by name in Brandtree content MDX; no import is needed. Pass any required `brand`, `ui`, or `dir` props explicitly from `props.brand`, `props.ui`, and `props.dir`; the generated route supplies these values to the document. The optional `class` prop adds a class to the outer element; other HTML attributes are not forwarded automatically.

This component requires both `brand` and `ui`. Named swatches (`brand.colors.swatches`) are editorial selections; palette families (`brand.colors.palette`) contain the shade scales. Their IDs serve different selectors.

Optional: `only` (swatch IDs), `threshold` (default `4.5`), `class`. Computes foreground/background contrast for the selected swatches. Filtering preserves configuration order; unknown selected IDs are silently omitted. It differs from the ordered `only` selector on `ColorPalette`.

## Usage

```mdx
<ContrastMatrix brand={props.brand} ui={props.ui} threshold={4.5} />
```

The threshold controls the matrix's pass indication; inspect actual text sizes and intended use before choosing a different threshold.
