## Usage

Import image files so Astro can optimize them and generate responsive sources.
The path below assumes a page at the content root; use your own asset and adjust
the path for nested or localized content.

```mdx
import photo from "../assets/photography/photo-01.jpg";

<PhotoGrid images={[{ src: photo, caption: "The studio in morning light" }]} />
```

Use a bare imported image when it is decorative. Add a caption when the image
needs a visible description and alt text.

## Images and responsive spans

Each caption also supplies the image’s alt text. Without a caption, the image is
treated as decorative. The component accepts imported image metadata, not plain
URL strings. Images crop to the chosen `ratio`.

Below `48rem`, the grid uses two columns regardless of `cols`. Keep spans at `1`
or `2`, and no greater than your desktop column count, so an item does not create
extra grid columns. A span changes the tile’s width; `ratio` still determines
that tile’s width-to-height proportion.
