`PhotoGrid` is available by name in Brandtree content MDX; no import is needed. Pass any required `brand`, `ui`, or `dir` props explicitly from `props.brand`, `props.ui`, and `props.dir`; the generated route supplies these values to the document. The optional `class` prop adds a class to the outer element; other HTML attributes are not forwarded automatically.

**Required:** `images`, an array of imported Astro images or `{ src: importedImage, caption?: string, span?: number }` objects. Optional: `cols` (default `3`), `ratio` (default `"4 / 3"`), `treatment` (`"none"`, default, `"duotone"`, or `"mono"`), `class`. Plain URL strings are not supported.

## Usage

```mdx
import studio from "../../assets/photography/studio.jpg";
import detail from "../../assets/photography/detail.jpg";

<PhotoGrid
  images={[
    { src: studio, caption: "The studio in morning light", span: 2 },
    { src: detail, caption: "A close view of the printed identity" },
  ]}
  cols={3}
  ratio="3 / 2"
  treatment="mono"
/>
```

Each caption also supplies the image's alt text. With no caption, the image is treated as decorative. `duotone` uses the configured primary color. On narrow screens the grid uses two columns regardless of `cols`; keep spans at `1` or `2` when authoring responsive layouts.
