## Usage

Use `LayoutGrid` to document a layout specification. With no props, it draws a
12-column canvas at a `16 / 9` aspect ratio.

```mdx
<LayoutGrid />
```

The default preview adds a label and specification row. This diagram describes
a composition; to arrange actual page content, use [Grid](/components/grid).

## Diagram scale

The drawing scales the stated margin to one quarter and the gutter to one half
so the diagram stays readable. These values affect the drawing; they do not
configure the website's layout. Add `specs` when the real dimensions need to
appear as text below the diagram.

Use positive whole numbers for columns and CSS lengths for margins and gutters.
The component has no content slots.
