`LayoutGrid` is available by name in Brandtree content MDX; no import is needed. Pass any required `brand`, `ui`, or `dir` props explicitly from `props.brand`, `props.ui`, and `props.dir`; the generated route supplies these values to the document. The optional `class` prop adds a class to the outer element; other HTML attributes are not forwarded automatically.

A layout-specification diagram. Optional: `columns` (default `12`), `gutter` (default `"30px"`, a label; the visual is proportional), `margin` (default `"100px"`, CSS length), `ratio` (default `"16 / 9"`), `label`, `specs` (array of `{ term: string, value: string }`, default empty), `class`.

## Usage

```mdx
<LayoutGrid
  columns={12}
  gutter="24px"
  margin="48px"
  ratio="16 / 9"
  label="Desktop composition"
  specs={[{ term: "Alignment", value: "Content follows the column grid" }]}
/>
```

This illustrates the grid you are documenting. It does not set the website's layout system; use configuration for the framework's own layout tokens.
