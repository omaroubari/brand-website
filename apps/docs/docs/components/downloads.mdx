## Usage

Pass the current brand to list its configured downloads. Maintain file URLs and
metadata in configuration; see [Assets](/assets) for preparing the files.

```mdx
<Downloads brand={props.brand} />
```

## Examples

## Selection and empty states

Omitting `items` uses `brand.downloads`. Passing an empty array renders nothing,
as does a brand without downloads.

Provided entries are matched against the current brand by `id`. A matching
configured entry replaces the supplied object, preserving its localized label
and note. The implementation also falls back to matching `href` for an item
without an ID, although the typed `BrandDownload` contract requires an `id`.
Use configured entries when selecting assets.

The component renders links with the `download` attribute. It does not create
archives or collect assets, so each configured URL must point to a real file.

Each `BrandDownload` requires `id`, `label`, and `href`; `format`, `size`, and
`note` are optional strings. No content slot is rendered.
