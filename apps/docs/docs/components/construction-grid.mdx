## Usage

Pass the current brand to show the brandmark on a square, ten-by-ten field.
Configure the source artwork in [Logos](/logos).

```mdx
<ConstructionGrid brand={props.brand} />
```

## Examples

### Use a rectangular field

Choose separate horizontal and vertical divisions for a wider mark. Supply a
caption that explains your actual artwork rather than relying on the generic caption.

<ComponentPreview path="construction-grid-logotype" code={variantCode} />

## Grid behavior

`cols` and `rows` control both the division count and the field’s aspect ratio.
The grid is an illustration over the supplied artwork, not an SVG geometry
editor; it does not inspect paths or prove that curves align with grid lines.
Use positive division counts.
