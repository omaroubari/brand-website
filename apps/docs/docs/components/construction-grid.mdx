`ConstructionGrid` is available by name in Brandtree content MDX; no import is needed. Pass any required `brand`, `ui`, or `dir` props explicitly from `props.brand`, `props.ui`, and `props.dir`; the generated route supplies these values to the document. The optional `class` prop adds a class to the outer element; other HTML attributes are not forwarded automatically.

This component requires `brand`. Artwork, aspect ratios, alt text, clearspace, and approved colorways come from `brand.logo`; set them in configuration rather than copying asset URLs into every page. Wherever supported, `mark` is `"logotype"` (default) or `"brandmark"`.

Optional: `mark` (default **`"brandmark"`**), `cols` (default `10`), `rows` (default `10`), `caption`, `class`. Overlays divisions on the artwork; it is an illustration rather than an SVG geometry editor.

## Usage

```mdx
<ConstructionGrid
  brand={props.brand}
  mark="brandmark"
  cols={8}
  rows={8}
  caption="Construction grid for the mark"
/>
```
