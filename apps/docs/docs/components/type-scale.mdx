## Usage

Pass the current brand and interface strings to show every configured type style
in configuration order. Define the styles in [Typography](/typography).

```mdx
<TypeScale brand={props.brand} ui={props.ui} />
```

## Examples

### Focus on a few styles

This example takes the last three configured styles, hides print specifications, and supplies fallback sample text. Pass names or IDs to `only` to choose a different order.

## Selection and sample text

`only` preserves the order you supply. Unknown names or IDs throw an error; an
empty array renders no rows. Without `only`, every configured style appears.

A style’s own `sample` takes precedence over the component’s `sample` prop.
Print specifications appear only when `print` is enabled and the style has a
`print` entry.
