## Usage

Supply one row per pair of traits. A position of `0` sits at the left label,
`100` sits at the right label, and `50` sits in the middle.

```mdx
<ToneSliders items={[{ left: "Formal", right: "Conversational", at: 70 }]} />
```

## Reading the scale

These markers communicate editorial positioning; they are static illustrations
rather than draggable controls. Each track has an accessible text description of
its labels and position. Keep `at` between `0` and `100`: the visual marker clamps
out-of-range values, but the accessible description reports the supplied value.
