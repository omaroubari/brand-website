## Usage

Supply a title and plain-text explanation for each value. Values appear in the
order you provide, with two-digit numbers beside their headings.

```mdx
<ValueGrid
  items={[{ title: "Clarity", body: "Make the important thing easy to find." }]}
/>
```

## Examples

### Remove the visible numbering

Hide the superscript numbers when the values should read as a set of equal principles.

## Content and layout

`body` accepts plain text, not nested MDX. The component always uses an ordered
list, even with visible numbering hidden. At `48rem` and above, each heading and
explanation sit side by side; below that width they stack.
