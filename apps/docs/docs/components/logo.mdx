## Usage

Pass the current brand to render its logotype. Configure artwork, aspect ratios,
and alternative text in [Logos](/logos).

```mdx
<Logo brand={props.brand} />
```

## Examples

### Show the brandmark

Select `brandmark` for the symbol alone. Use `width` to size either mark; its height follows the configured aspect ratio.

<ComponentPreview path="logo-brandmark" code={example0} />

### Use a fixed background

Match `on` to the panel’s background so the artwork stays legible when the page theme changes. This example uses configured neutral shades; choose palette tokens from your own brand.

<ComponentPreview path="logo-background" code={example1} />

### Tint a single-color mark

Use a configured CSS token to recolor a single-color SVG.

## Artwork and theme behavior

`on="auto"` switches between the configured light and dark artwork with the page
theme, including the system preference when no explicit theme is selected. It
works without JavaScript. `on="light"` and `on="dark"` choose artwork for a fixed
background; they do not paint that background.

`tint` takes precedence over `on` and uses the light-background SVG as a mask.
It replaces all artwork colors with one color, so avoid it for multicolor marks.
For approved pairings and protected space, see
[LogoColorways](/components/logo-colorways) and
[LogoClearspace](/components/logo-clearspace).
