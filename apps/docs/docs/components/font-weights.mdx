## Usage

Pass the current brand to display each configured weight using its name as the
sample text. Weights come from `brand.typography.weights`; see
[Typography](/typography) for font setup.

```mdx
<FontWeights brand={props.brand} />
```

## Examples

### Compare a consistent phrase

Choose the text family and repeat the same phrase so changes in weight are easier to compare.

<ComponentPreview path="font-weights-text" code={example0} />

## Font availability

Rows follow configuration order, including entries marked italic. The selected
family must have the corresponding font weights and styles loaded for an accurate
specimen; adding a configuration entry alone does not load a font file.
