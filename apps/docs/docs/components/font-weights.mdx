`FontWeights` is available by name in Brandtree content MDX; no import is needed. Pass any required `brand`, `ui`, or `dir` props explicitly from `props.brand`, `props.ui`, and `props.dir`; the generated route supplies these values to the document. The optional `class` prop adds a class to the outer element; other HTML attributes are not forwarded automatically.

## Props and behavior

<TypeTable
  type={{
    brand: {
      type: "BrandConfig",
      required: true,
      description: "Resolved brand for the current locale. Pass props.brand.",
    },
    font: {
      type: '"display" | "text"',
      default: '"display"',
    },
    sample: {
      type: "string",
      description: "Text rendered at each weight.",
    },
    class: {
      type: "string",
      description: "Additional class on the outer element.",
    },
  }}
/>

**Required:** `brand`. Optional: `font` (`"display"`, default, or `"text"`), `sample`, `class`. Shows every configured `brand.typography.weights` entry, including italic entries. Without `sample`, each row uses the weight's configured name. The requested font weight must also be available in your loaded font files.

## Usage

```mdx
<FontWeights brand={props.brand} font="text" sample="Words with purpose" />
```
