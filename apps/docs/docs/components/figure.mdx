## Usage

Import an image and pass the current interface strings. Supply meaningful alt
text when the image conveys information; leave it empty for decorative artwork.

```mdx
import photo from "../assets/photography/photo-01.jpg";

<Figure
  ui={props.ui}
  src={photo}
  alt="A photograph demonstrating the brand's image treatment"
/>
```

This import assumes a document at the content root. Use your own asset and adjust
the path for nested or localized pages. Imported images use Astro's responsive
image pipeline. A string `src`, such as a path under `public/`, produces an
ordinary lazy-loaded image instead.

## Image behavior

`cover` fills the frame and can crop the image; `contain` keeps the whole image
visible, as shown in the default preview. The default ratio applies to images
and placeholders alike.

An empty frame displays its caption, or the localized artwork-pending label
when no caption is provided. A nonempty caption also renders below the frame.
`bg` selects a generated CSS custom property directly; unlike `Panel.bg`, it
does not validate the token. The component has no content slots.
