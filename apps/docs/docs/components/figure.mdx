`Figure` is available by name in Brandtree content MDX; no import is needed. Pass any required `brand`, `ui`, or `dir` props explicitly from `props.brand`, `props.ui`, and `props.dir`; the generated route supplies these values to the document. The optional `class` prop adds a class to the outer element; other HTML attributes are not forwarded automatically.

An image or placeholder with an optional caption. **Required:** `ui`. Optional: `src` (imported Astro `ImageMetadata` or URL string), `alt` (default empty), `caption`, `ratio` (default `"4 / 3"`), `fit` (`"cover"`, default, or `"contain"`), `bg` (a generated `--color-*` suffix), `class`.

## Usage

```mdx
<Figure
  ui={props.ui}
  src="/mockups/stationery.jpg"
  alt="Letterhead and envelope with the primary logo in the top corner"
  caption="Stationery application"
  ratio="3 / 2"
  fit="contain"
/>

<Figure
  ui={props.ui}
  ratio="9 / 16"
  caption="Mobile layout — artwork pending"
/>
```

Imported images use Astro's responsive image pipeline. String paths render ordinary lazy-loaded images. Without `src`, the frame displays `caption` or the localized artwork-pending label. `bg` directly selects a CSS custom property; unlike `Panel.bg`, it does not validate or resolve the reference. Use meaningful alt text for informative images; empty alt is suitable for purely decorative artwork.
