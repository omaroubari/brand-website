## Usage

Introduce the configured display family.
Family names, foundries, notes, and links come from `brand.typography.families`;
see [Typography](/typography) for configuration.

```mdx
<TypeSpecimen />
```

## Examples

### Introduce the text family

The first preview uses the display family with `glyph="Aa"` at weight `500`. Switch to the text family and use `glyph="Ag"` at weight `400` to compare its letterforms. Both family entries in the sample brand use DM Sans; their labels and metadata identify their different roles.

<ComponentPreview path="type-specimen-text" code={example0} />

## Family metadata

`font` selects both the CSS family token and the matching family metadata. Foundry,
note, and licence/download link appear only when configured. The component uses
the fonts already loaded by the site; it does not download fonts from the family link.
