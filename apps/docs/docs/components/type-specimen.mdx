## Usage

Pass the current brand and interface strings to introduce the display family.
Family names, foundries, notes, and links come from `brand.typography.families`;
see [Typography](/typography) for configuration.

```mdx
<TypeSpecimen brand={props.brand} ui={props.ui} />
```

## Examples

### Introduce the text family

Switch to the text family and use a lighter weight with characters that show its letterforms.

## Family metadata

`font` selects both the CSS family token and the matching family metadata. Foundry,
note, and licence/download link appear only when configured. The component uses
the fonts already loaded by the site; it does not download fonts from the family link.
