`ColorScale` is available by name in Brandtree content MDX; no import is needed. Pass any required `brand`, `ui`, or `dir` props explicitly from `props.brand`, `props.ui`, and `props.dir`; the generated route supplies these values to the document. The optional `class` prop adds a class to the outer element; other HTML attributes are not forwarded automatically.

This component requires both `brand` and `ui`. Named swatches (`brand.colors.swatches`) are editorial selections; palette families (`brand.colors.palette`) contain the shade scales. Their IDs serve different selectors.

    },

Optional: `only` (palette **family** IDs in display order), `class`. Defaults to all configured families. Displays the published shade stops from `50` through `950`. Unknown selected family IDs throw an error.

## Usage

```mdx
<ColorScale brand={props.brand} ui={props.ui} />
```
