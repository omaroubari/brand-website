## Usage

Pass the current brand to show the built-in demonstration sizes.
Set the published digital and print minimums in [Logos](/logos).

```mdx
<LogoScaling brand={props.brand} />
```

## Examples

### Publish application sizes

Replace the demonstration sizes with the specifications your brand actually uses.
Each label is editorial copy; the component does not convert CSS lengths to print measurements.

```mdx
<LogoScaling
  brand={props.brand}
  sizes={[
    { width: "12rem", label: "Standard application" },
    { width: "4rem", label: "Small digital application" },
  ]}
/>
```

This is the size set shown in the opening preview. Supply sizes largest first;
the component preserves the array order rather than sorting it.

## Size behavior

The built-in demonstration widths and labels are:

| Width      | Label          |
| ---------- | -------------- |
| `18rem`    | 288 px / 49 mm |
| `11.25rem` | 180 px / 30 mm |
| `9rem`     | 144 px / 24 mm |
| `4.5rem`   | 72 px / 12 mm  |
| `2.25rem`  | 36 px / 6 mm   |

The minimum-size caption always reads `brand.logo.minSize.digital` and
`brand.logo.minSize.print`. Changing `sizes` or `mark` does not change those
values or prevent artwork from rendering below the stated minimum.
