## Usage

Pass the current brand to display every approved colorway for the logotype.
Define the foreground, background, and optional label of each combination in
[Logos](/logos).

```mdx
<LogoColorways brand={props.brand} />
```

## Examples

### Use two columns for the logotype

The opening preview sets `cols={2}` to show approved logotype pairs in a compact
grid. Compare it with the default three-column brandmark example below.

```mdx
<LogoColorways brand={props.brand} cols={2} />
```

### Show brandmark colorways

Set `mark="brandmark"` to apply the same approved combinations to the standalone mark.

<ComponentPreview path="logo-colorways-brandmark" code={variantCode} />

### Publish approved combinations

Replace `brand.logo.colorways` in `brandtree.config.ts` to change the rendered
pairs. This fragment uses the universal `black` and `white` references. Add
palette tokens from your own configuration for other approved combinations.
An omitted label leaves just the generated foreground/background caption.

```ts
colorways: [
  { id: "primary", fg: "black", bg: "white", label: "Light" },
  { id: "reversed", fg: "white", bg: "black" },
],
```

## Layout and selection

Every entry in `brand.logo.colorways` is rendered in configuration order; there
is no `only` filter. `cols` controls the layout from `48rem` up. Below that
viewport width, the grid always uses two columns, including when `cols={1}`.
