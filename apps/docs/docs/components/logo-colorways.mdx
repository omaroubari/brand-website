`LogoColorways` is available by name in Brandtree content MDX; no import is needed. Pass any required `brand`, `ui`, or `dir` props explicitly from `props.brand`, `props.ui`, and `props.dir`; the generated route supplies these values to the document. The optional `class` prop adds a class to the outer element; other HTML attributes are not forwarded automatically.

This component requires `brand`. Artwork, aspect ratios, alt text, clearspace, and approved colorways come from `brand.logo`; set them in configuration rather than copying asset URLs into every page. Wherever supported, `mark` is `"logotype"` (default) or `"brandmark"`.

Optional: `mark`, `cols` (default `3`), `class`. Displays every configured `brand.logo.colorways` entry. There is no `only` filter.

## Usage

```mdx
<LogoColorways brand={props.brand} cols={2} />
```
