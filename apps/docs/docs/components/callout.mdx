## Usage

Pass the interface strings and put the explanation in the default slot. Without
a title or tone, the heading uses the localized note label.

```mdx
<Callout ui={props.ui}>

Use the supplied artwork for every application.

</Callout>
```

The default preview sets `tone="note"` explicitly; omitting it produces the same note treatment.

## Examples

### Add an editorial note

Use `tone="note"` for supporting information. Leaving out `title` keeps the
localized note heading.

<ComponentPreview path="callout" code={previewCode} />

### Mark a recommended use

Use `tone="do"` for a positive rule. Omit `title` to keep the localized heading
for that tone; a custom title replaces that heading rather than translating it.

<ComponentPreview path="callout-recommended" code={example0} />

### Explain a prohibited use

Use `tone="dont"` for a prohibition and a custom `title` to name the rule.
The title replaces the localized heading and is rendered exactly as supplied.
