`Callout` is available by name in Brandtree content MDX; no import is needed. Pass any required `brand`, `ui`, or `dir` props explicitly from `props.brand`, `props.ui`, and `props.dir`; the generated route supplies these values to the document. The optional `class` prop adds a class to the outer element; other HTML attributes are not forwarded automatically.

An editorial note or usage rule with a default slot. **Required:** `ui`. Optional: `tone` (`"note"`, default, `"do"`, or `"dont"`), `title` (defaults to the localized label for the tone), `class`.

## Usage

```mdx
<Callout ui={props.ui} tone="dont" title="Keep the original proportions">

Do not stretch or compress the supplied artwork.

</Callout>
```
