## Usage

Pass the interface strings and put the explanation in the default slot. Without
a title or tone, the heading uses the localized note label.

```mdx
<Callout ui={props.ui}>

Use the supplied artwork for every application.

</Callout>
```

The default preview adds a custom title and the `dont` tone for a prohibited use.

## Examples

### Mark a recommended use

Use `tone="do"` for a positive rule. Omit `title` to keep the localized heading
for that tone; a custom title replaces that heading rather than translating it.
