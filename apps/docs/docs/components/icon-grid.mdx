## Usage

Supply an array of named SVG source strings. This inline example is complete;
for larger sets, export the array from your own asset module as in the preview.

```mdx
<IconGrid
  icons={[
    {
      name: "circle",
      svg: '<svg viewBox="0 0 24 24" fill="none" stroke="currentColor"><circle cx="12" cy="12" r="8" /></svg>',
    },
  ]}
/>
```

The preview’s import assumes a page at the content root. Adjust the path for
nested or localized content. The component does not discover SVG files.

## Selection and construction grid

Without `only`, icons sort alphabetically by name. An unknown selected name throws
an error; an empty selection renders no tiles. The first displayed tile gets the
construction grid; `unit` changes the overlay divisions, not the SVG’s view box.

Below `48rem`, the layout uses two columns regardless of `cols`. SVG strings render
as HTML, so supply trusted project assets.
