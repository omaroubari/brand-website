`IconGrid` is available by name in Brandtree content MDX; no import is needed. Pass any required `brand`, `ui`, or `dir` props explicitly from `props.brand`, `props.ui`, and `props.dir`; the generated route supplies these values to the document. The optional `class` prop adds a class to the outer element; other HTML attributes are not forwarded automatically.

The media imports assume a page at the content root. Use your own assets and

**Required:** `icons`, an array of `{ name: string, svg: string }`. Optional: `only` (names in display order), `unit` (default `24`, overlay grid), `version` (default `"v1.0"`), `cols` (default `4`), `class`.

## Usage

```mdx
import { icons } from "../../assets/icons/index.ts";

<IconGrid icons={icons} unit={24} cols={4} version="v1.0" />
```

Supply SVG source strings from your own asset module; the component does not discover files. Without `only`, names sort alphabetically. Unknown names in `only` throw an error. SVG markup is rendered as HTML, so use trusted project assets. Adapt the import path to the location of your MDX file.
