## Usage

Pass at least one misuse rule. The effect creates the visual
mistake; the title and note explain what readers should do instead.
The artwork comes from [Logos](/logos).

```mdx
<LogoMisuse
  items={[
    {
      effect: "stretch",
      title: "Do not stretch",
      note: "Keep the original proportions.",
    },
  ]}
/>
```

## Examples

### Pair each mistake with a rule

Add entries in the order you want readers to encounter them. The opening
preview pairs stretching and rotation in a two-column grid.

```mdx
<LogoMisuse
  cols={2}
  items={[
    {
      effect: "stretch",
      title: "Do not stretch",
      note: "Keep the original proportions.",
    },
    {
      effect: "rotate",
      title: "Do not rotate",
      note: "Keep the artwork upright.",
    },
  ]}
/>
```

## Effects and layout

`MisuseEffect` accepts `"stretch"`, `"recolor"`, `"low-contrast"`, `"too-small"`,
`"obstruct"`, `"rotate"`, `"outline"`, `"shadow"`, and `"pattern"`. These are preset
visual treatments, not measurements or validators for uploaded artwork.

Items are numbered automatically from one in array order. `cols` applies from
`48rem` up; narrower viewports always use two columns. An empty `items` array
renders an empty grid.
