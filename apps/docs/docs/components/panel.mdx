## Usage

Pass the brand and put artwork in the default slot. Omitting `ratio` lets the
content determine the frame height.

```mdx
<Panel brand={props.brand}>
  <Logo brand={props.brand} width="60%" />
</Panel>
```

The preview uses the first configured logo colorway, a `16 / 9` frame, and a
label and caption. Define approved pairs in [Logo configuration](/logos).

## Color and caption behavior

With `bg` set and `fg` omitted, the foreground uses CSS `contrast-color()`.
With neither prop, the implementation sets the foreground to black. For a
text-bearing panel with fixed colors, supply both configured `bg` and `fg`.
An unknown color token throws an error during rendering.

Set `flush` to remove the frame's padding when artwork should reach its edges.

The default slot contains the artwork. A named `caption` slot replaces the
caption text, but a nonempty `caption` prop is still needed to create the
caption element. For example:

```mdx
<Panel brand={props.brand} caption="Primary logo">
  <Logo brand={props.brand} width="60%" />
  <span slot="caption">
    Primary logo. <strong>Use supplied artwork.</strong>
  </span>
</Panel>
```
