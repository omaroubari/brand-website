`SpecList` is available by name in Brandtree content MDX; no import is needed. Pass any required `brand`, `ui`, or `dir` props explicitly from `props.brand`, `props.ui`, and `props.dir`; the generated route supplies these values to the document. The optional `class` prop adds a class to the outer element; other HTML attributes are not forwarded automatically.

An ordered description list. **Required:** `items`, an array of `{ term: string, value: string }`. Optional: `inline` (default `false`), `class`.

## Usage

```mdx
<SpecList
  items={[
    { term: "Format", value: "SVG" },
    { term: "Use", value: "Digital artwork" },
  ]}
/>
```

Use the stacked default for long values. The inline layout places pairs side by side and needs particular care on narrow screens.
